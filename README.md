# חשבוניה

אפליקציה אישית ללימוד ותרגול מתמטיקה לכיתה ה׳, לפי פריסת תכנית הלימודים של סדרת ה.ש.ב.ח.ה, בתוספת ארבעה נושאים מתכנית משרד החינוך.

## איך פותחים
- **הכי פשוט:** לפתוח את `dist/heshboniya.html` בדפדפן (קובץ אחד שכולל הכול).
- **אחרי שינוי בקוד:** להריץ `python3 tools/build.py` כדי לבנות מחדש את הקובץ.
- ההתקדמות נשמרת בדפדפן של המכשיר. אפשר כמה פרופילים (כמה ילדים) על אותו מכשיר.

## מה יש בפנים
- **ארבעה עולמות**, אחד לכל ספר: עיר המספרים, ממלכת השברים, כוכב העשרוניים ואי הצורות. בכל אחד מהם יחידות ונושאים לפי סדר הלימוד, עם התאריכים ועמודי הספר.
- **התאמה אישית:** שם, מגדר (כל ההסברים והשאלות בלשון הנכונה), ערכת צבעים שנבחרת לפי המגדר וניתנת לשינוי, ותחומי עניין שעליהם נבנות השאלות המילוליות.
- **כל נושא:** כרטיסי הסבר עם המחשות ודוגמה פתורה, ואחריהם תרגול אדפטיבי.
- **תרגול אדפטיבי עד רף שליטה:** השאלות מתחילות ברמה 1 ועולות בהדרגה אחרי הצלחות. אחרי טעויות הן חוזרות לרמה קלה יותר. מד השליטה מתמלא עד 45% ברמה 1 ועד 75% ברמה 2. כדי להגיע לרף של 80% צריך להצליח בשאלות האתגר.
- **רמז אחרי טעות ראשונה, פתרון מלא אחרי טעות שנייה.** כל טעות נשמרת לחזרה בלשונית "טעויות".
- **"בכיתה לומדים עכשיו":** הנושאים שמתאימים לתאריך הנוכחי לפי לוח הזמנים.
- **אתגר 60 שניות**, יעד יומי, רצף ימים, תגים, רמות, הקראה בקול ודוח התקדמות להורים.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `js/curriculum.js` | מפת הנושאים: עולמות, יחידות, תאריכים, עמודים ומיומנויות |
| `js/content/*.js` | התוכן: הסברים ומחוללי שאלות לכל נושא (לפי `CONTENT_SPEC.md`) |
| `js/engine.js` | הצגת שאלות מכל הסוגים ובדיקתן |
| `js/app.js` | המסכים והזרימה |
| `js/store.js` | פרופילים, שליטה, כוכבים, תגים וערכות צבעים |
| `js/viz.js` | ספריית ההמחשות (שברים, ישר מספרים, צורות, דיאגרמות) |
| `tests/run.sh` | בדיקה אוטומטית של כל מחוללי השאלות |
| `tests/sample.sh` | הדפסת דוגמאות של שאלות והסברים לבדיקת ניסוח |
